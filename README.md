# A portfolio about myself

It's mostly for me but it's under [Unlicense](https://github.com/notmithun/notmithun.github.io?tab=Unlicense-1-ov-file) so anyone can take this for free!



## How it works

It uses plain HTML, CSS, JavaScript so you don't need anything to run this like Node.js

- Uses [Iconify](https://iconify.design/) for the icons.
- Uses the font [Unbounded](https://fonts.google.com/specimen/Unbounded) from Google Fonts
- Particles are from [tsParticles](https://github.com/tsparticles/tsparticles)
- Favicons were generated by [favicon.io](https://favicon.io/)
- [AniList API](https://docs.anilist.co/) is used for what anime I'm currently watching
