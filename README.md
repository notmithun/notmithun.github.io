## How it works

It uses plain HTML, CSS, and JavaScript, so you don't need anything like Node.js to run it.

- Uses [Iconify](https://iconify.design/) for icons  
- Uses the font [Unbounded](https://fonts.google.com/specimen/Unbounded) from Google Fonts  
- Particles are powered by [tsParticles](https://github.com/tsparticles/tsparticles)  
- Favicons were generated using [favicon.io](https://favicon.io/)  
- [AniList API](https://docs.anilist.co/) is used to show what anime I'm currently watching
